Help & feedback

How do I install it?

Android: open the link in Chrome, tap the menu (⋮), then Install app or Add to Home screen.

iPhone or iPad: open it in Safari, tap Share, then Add to Home Screen. This also stops Safari clearing your entries if you don't open the app for a while.

Windows or Mac: open it in Chrome or Edge and click the install icon at the right of the address bar (or menu, then Install).

The first time you open it, choose your home town. That's all the setup there is.

Where are my entries saved?

On this device only. Nobody else can see them, including the person who made the app. Use Settings, then Download backup now and then, and keep the file somewhere safe.

Where do the weather and pollen come from?

Weather is Open-Meteo model data for your home town, or for wherever you are when the arrow button is on. Pollen is the weekly count from the nearest UCT Lung Institute sampling site within 100 km; some areas have no site nearby. Air quality (fine particles and dust) is daily model data from Copernicus via Open-Meteo, compared with the WHO 24-hour limits.

Can I use it on my phone and my computer? (optional GitHub sync)

Normally each device keeps its own entries. If you want the same diary on several devices, with automatic backup and history, you can sync it to a free, private GitHub repository that only you can see. It takes about 10 minutes, once.

  1. Create a free account at github.com/signup.
  2. Make a new repository: tap +, then New repository. Name it sinus-log-data, choose Private, tick Add a README, then Create repository.
  3. Create an access token at github.com/settings/personal-access-tokens/new:
    • Name: Sinus Log – phone (or computer). Expiration: 1 year.
    • Repository access: Only select repositories, then pick sinus-log-data.
    • Repository permissions: Contents, set to Read and write. Leave everything else.
    • Tap Generate token and copy it. GitHub shows it only once.
  4. In this app: Settings, then Sync between devices. Enter your GitHub username, sinus-log-data and the token, then tap Connect. It should say Connected … (private).
  5. Repeat step 4 on each device, ideally with its own token, so you can switch one off without affecting the others.

Your entries already on the device are uploaded on the first sync. The token is stored only on that device and is sent only to GitHub. Never paste it into a chat or email; if it leaks, delete it on GitHub and make a new one. Keep the repository private, because it holds your health diary.

What does the Suspects table mean?

For each factor it compares how often it was present on your bad days (6 or higher) with your other days. A big gap is worth a closer look. It shows patterns, not causes, and isn't medical advice: see your doctor about symptoms that worry you.

What do Send and Copy message do?

Send opens your phone's share menu with the message ready. Choose WhatsApp or email and send it to the person who shared the app with you. On a computer without a share menu, it copies the message instead.

On this device the app is connected to GitHub, so Send adds the message straight to the ideas list (IDEAS.md) in your data repo instead.

Copy message copies the message so you can paste it anywhere. Each message includes its type (idea, bug or question), your name if you add one, and the app version, device type and screen size to help fix bugs. Your log entries are never included.

The full-moon test

The full-moon window is the 3 days either side of full moon, about 20% of every cycle. If the moon has nothing to do with it, roughly 1 in 5 flare days will land in the window by chance.

Suspects

How often each factor was present on your flare days (6 or higher) compared with your other logged days. Weather counts if it hit on the day or the day before, since sinuses often react with a lag. A factor needs at least 4 flare days and a clear gap before it gets highlighted.

Pollen: weekly counts from the UCT Lung Institute sampling site nearest to where each day was logged (within 100 km). Each report covers the 7 days up to its date; weeks a site wasn't sampled are left out of this table.
