# Moonlit Sinus Log

Installable web app for logging daily sinus congestion against moon phase and Hout Bay weather.

- **Use it:** https://therustyfareye.github.io/sinus-log-app/
- **Install:** Android Chrome → menu → *Install app*. Windows Edge/Chrome → install icon in the address bar.
- **Data:** this repo holds no personal data. Entries are kept on each device and synced to a separate private repo through the GitHub API, using a fine-grained token stored only on that device.
